Create a campaign

Anyone can create an allowlist campaign. Registration is gated on-chain to Agent ID holders.

How it works

  1. A project creates a campaign with a slot limit and a deadline.
  2. Agent ID holders register with one transaction. The contract checks on-chain that the caller holds an Agent ID (balanceOf > 0 on the Agent ID registry).
  3. Each user can hold exactly one non-transferable Agent ID, so one registration per address means one slot per real holder — no sybil farming.
  4. Projects export the registrant list on-chain and use it for their mint or claim.

AgentGate never holds or moves user funds. Only a campaign's creator can close that campaign early. This site asks your wallet to sign transactions — you always confirm them yourself in your wallet. Never share a seed phrase or private key with any site, including this one.
